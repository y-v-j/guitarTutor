Reference pitch
A4 = 440 Hz

  • Eddie Ate Dynamite, Good Bye Eddie: E A D G B E, thick string to thin.
  • Tune up to the note. If you go sharp, drop below it and come back up; the string holds its pitch better.
  • No tuner handy? Get the low E right, then match the 5th fret of each string to the next open string. Use the 4th fret on the G string to tune the B.
  • Check twice. Tightening one string pulls the neck a little, so do a second pass.
